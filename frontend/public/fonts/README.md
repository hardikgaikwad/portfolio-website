# Thugolatz Webfont Directory

Place `Thugolatz.woff2`, `Thugolatz.woff`, or `Thugolatz.ttf` in this directory.

The website's CSS is pre-configured to load the font from:
- `local('Thugolatz')` (if installed on your OS)
- `/fonts/Thugolatz.woff2`
- `/fonts/Thugolatz.woff`
- `/fonts/Thugolatz.ttf`

The font is declared centrally in `src/styles/variables.css` under `--font-display`.
